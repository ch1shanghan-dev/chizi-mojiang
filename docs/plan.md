## 附：这轮审查发现的既有问题（供 P3 决策）

**生涯成就的分布**（`core/csh_achv.js`，434 条）：

| 分类 | 条数 | 形态 |
|---|---|---|
| 官阶 | 55 | 单一字段 `rank` 的 1→50 阶梯 |
| 功勋 | 37 | `merit` / `meritToday` 阈值 |
| 资产 | 40 | `pc` / `pcPeak` / 落魄反向 |
| 签到 | 16 | `streak` 阈值 |
| 胜负 | 70 | 场次/胜场/败场/击杀/武将数/模式数 |
| AI世界 | ~81 | 世界档案统计 |
| 豪赌桌 | ~66 | 豪赌桌统计 |
| 任务 / 互动 / 彩蛋 | 44 | 少量事件型 |
| BOSS 挑战 | ~25 | 讨伐数 |

结论：**字段全部真实存在（37 个引用字段在 `buildStats` 里一个不缺），错不在数据源，错在形式**——几乎是同一个数字换个阈值重复 10~20 次。玩家看到的是"再来一点"，不是"我做到了什么"。这就是池子成就存在的理由；同时也是 P3 第 11 项要做的减法。
