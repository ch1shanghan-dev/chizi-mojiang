# AI 世界垃圾话 · AI 语音（TTS）方案

> 2026-10-09 · 状态：**方案定稿，待作者拍板后实施**。前置依赖已完成：垃圾话精简择优
> （10,837 → 1,680 句，见 §2），本方案的合成工作量按精简后的池子计算。

## 1. 目标与非目标

**目标**：给 AI 世界的互动台词（砸蛋/送花/回嘴/终局/被控吐槽……）配上 AI 语音，
让"垃圾话"从纯文字气泡变成真的有人在牌桌上说话。

**非目标**：
- 不重制现有 189 条武将技能语音（`audio/skill/*.mp3` 是另一套体系，互不干扰）；
- 不做实时流式 TTS（延迟与稳定性都不适合"插话"场景，见 §6 风险）；
- 联机不播（与 csh_interact 一致，联机本来就静默休眠）。

## 2. 语料规模（精简后）

| 池 | 句数 | 触发频率 | 建议优先级 |
|---|---|---|---|
| LINES 22 类（砸蛋/送花/回嘴/终局/被控 ctrl/重伤 hurtSelf…） | 1,296 | 中（限流 3s 全局 / 20s 单人） | P0 |
| TRASH.hitBack 回嘴 | 50 | 高（35% 概率被砸即回） | P0 |
| PERSONA_LINES 性格分声 4 场景 × 5 人格 | 182 | 高 | **P0（音色区分度最大）** |
| EMO_LINES + EMO_PERSONA 表情台词 | ~130 | 中 | P1 |

**合计 ≈ 1,680 句**。按平均 2.5s/句、48kbps MP3 ≈ 15KB/s：
**全量 ≈ 1,680 × 2.5s × 15KB/s ≈ 63MB**（±人格变体重叠后预计 55~70MB）。
可接受但不小；P0 先合成 1,500 句主池，表情台词（P1）视效果追加。

## 3. 引擎候选对比（2026-10 现状）

| 引擎 | 音质/情感 | 中文音色 | 成本 | 风险 | 结论 |
|---|---|---|---|---|---|
| **Edge-TTS**（微软朗读接口） | 中上，情感平淡但稳 | 10+ 中文（晓晓/云希/云野/晓伊…） | **免费** | 非官方接口，理论可被限流（社区库 `edge-tts` 维护活跃，多年稳定） | **P0 主力** |
| Azure TTS（正式 API） | 同 Edge 音色库 + SSML 情感调 | 同上 + 更多 | 50 万字/月免费，超出 $16/1M 字 | 需订阅；SSML 情感对垃圾话提升有限 | 备胎（Edge 被限流时切换） |
| **CosyVoice 2**（阿里开源） | **顶级**，情感/语速/方言可控，支持音色克隆 | 出色 | 免费（本地 GPU 推理，RTX 3060 级即可） | 部署门槛；合成速度 ~实时比 | **P1 升级**（重点人格重出） |
| GPT-SoVITS | 高，few-shot 克隆，社区三国杀风模型多 | 高 | 免费（本地 GPU） | 训练/调参工作量大；单句稳定性一般 | 备选 P1 |
| ChatTTS | 对话感强 | 中 | 免费 | 数字/标点不稳定，笑声控制随机 | 不推荐 |
| 云厂商（阿里/腾讯语音合成） | 中 | 中 | ¥ 按量 | 音色 AI 味重，性价比低 | 不推荐 |

**决策：P0 = Edge-TTS 全量打底（零成本、一晚跑完）；P1 = 本地 CosyVoice 2 给 5 个人格
音色重出 PERSONA_LINES 182 句 + 高频 300 句（音色区分度与情感是"拟人"的最后一块）。**

## 4. 性格 → 音色映射（5 人格）

| 人格 | 世界观设定 | Edge-TTS 音色 | 语速/音调 | CosyVoice P1 方向 |
|---|---|---|---|---|
| aggro | 激进 | `zh-CN-YunjianNeural`（云健，磁性男声） | +10% / +2Hz | 暴躁青年，句尾上扬 |
| tight | 保守 | `zh-CN-YunyeNeural`（云野，沉稳男声） | -10% / -1Hz | 冷面账房，慢条斯理 |
| bluff | 虚张声势 | `zh-CN-YunxiNeural`（云希，少年感） | +15% / +0 | 贫嘴油滑，戏腔拖尾 |
| math | 数学家 | `zh-CN-XiaoyiNeural`（晓依，冷静女声） | 0 / -3Hz | 理性女声，平板冷静 |
| wild | 莽夫 | `zh-CN-YunyangNeural`（云扬，浑厚男声） | +5% / +3Hz | 大嗓门豪爽 |

非池子武将（哈希派生人格）按人格取音色 —— **同人格同音色**，跨武将仍有气泡名字区分，
不追求一将一声（1,680 句 × 98 将 = 不可行，也没必要：垃圾话是"人格"在说，不是"武将"在说）。

## 5. 产物与接入

### 5.1 文件组织

```
audio/interact/
  p_<persona>_<md5前10>.mp3    # 人格句（PERSONA_LINES / EMO_PERSONA）
  g_<cat>_<md5前10>.mp3        # 通用句（LINES / TRASH / EMO_LINES）
```

文件名 = 内容哈希：**文本改了缓存自动失效**，脚本幂等重跑只合成新增句。

### 5.2 播放链路（一个接入点，三处调用方）

`csh_interact.js` 新增：

```js
// lib.cshInteractAudio.say(player, line, persona) →
//   查 audio/interact/<key>.mp3 → game.playAudio → 失败静默回落纯气泡
```

- `say()` / `riposte()` / `chorus()` 三处在 `player.chat(line)` 之前调用；
- **气泡照出**（语音与文字同出，语音只是加分项）；
- 播放走引擎 `game.playAudio`（复用音量/静音设置）；与 csh_sfx 的 AudioContext 并存；
- 新配置键 `extension_池子魔将_csh_interact_tts`（默认开），设置面板加一行开关；
- 失败全静默（文件缺失/播放异常 → 只出气泡，永不报错，与 csh_voice 同款守卫）。

### 5.3 生成脚本（实施时新建）

`tools/gen_interact_tts.py`：
1. Node 侧 dump 全部台词池（复用本轮 lines_census 的加载器，含人格标注）；
2. 逐句调 `edge-tts --voice <音色> --rate/--pitch` 合成；
3. 幂等：目标文件存在且 md5 命中清单则跳过；
4. 产出 `tools/interact_tts_manifest.json`（句 → 文件 → 音色 → 时长），供播放端查表与体检。

预计 1,500 句 × ~1.2s/句 ≈ 30 分钟（受接口限速约束，夜里挂机跑）。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| Edge-TTS 非官方接口失效 | 清单驱动：失效只影响增量合成，已合成文件不受影响；备胎 Azure 同参数切换 |
| 语音与音效抢音频通道 | 实测 `game.playAudio` 并发行为后定：必要时语音走独立 `<audio>` 元素 + 统一音量键 |
| 63MB 体积 | P0 先出主池；加载零成本（按需 playAudio，不预载）；嫌大可降到 32kbps（−33%） |
| 语音太密变噪音 | 限流体系现成（3s 全局/20s 单人/每轮 3 次）；语音版给 chat 开关独立一档「文字+语音 / 仅文字」 |
| 语气词句合成质量差（"啧——""666"） | 生成脚本跳过清单：纯语气词/数字句（`^[0-9]+$`、"666"）不出语音，只出气泡 |
