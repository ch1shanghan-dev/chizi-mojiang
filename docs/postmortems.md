| 1 | 外部并入的技能整组不可用 | 键名扁平化时正则捕获组包含**前导下划线**，注册键与引用键差一字符 | 技能 ID 做过任何改写后，**三向核对**：武将 skills 数组 ↔ 技能注册键 ↔ 翻译键，一条 grep 的事，不能省 |

| 3 | 同 ID 双定义 | 源扩展与并入后的武将同 ID 共存 | 并入三件事一次做完：技能/翻译并入 + characterSort 归组 + **移除源扩展目录** |
| 4 | 自建浮层被宿主界面遮挡 | 层级低于宿主菜单，且挂载点选错 | 游戏内自建浮层：挂 `documentElement`、层级 **2147483000 档**（body 上的 transform 会建立独立层叠上下文，见 openRedeem 注释） |
| 5 | 在线下载不可用 | codeload 整包的 CORS 不放行任意 Origin；raw 单文件为 `*` | 下载方案先实测 CORS；"仓库根=扩展内容"布局走 API 文件树 + raw 逐文件 + `importExtension` 对象形态；**非该布局的仓库不得上架**，逐个验证 |
| 6 | 装备类效果时机判定失效 | onLose 里用 `getParent(2).name` 推断来源，层级随调用路径漂移 | 跨事件关联用**显式标记**（在事件对象上挂字段），与调用路径无关 |
| 7 | 标记名与技能语义脱节 | 批量/自动化生成的内容未经校对即入库 | 标记命名规范 = **技能名或描述里的效果词**；自动化产出必须人工全量校对（清单在 `tools/marks_audit.txt`） |
| 8 | 桩测试连正常路径都不过 | 桩内调用顺序与真实执行顺序相反 | 桩测试必须**复刻真实调用顺序** |
| 9 | 语法门禁全绿但运行异常 | 门禁只覆盖语法，不覆盖"注册键与引用一致"这类语义问题 | 语义一致性靠定向 grep（#1/#2 的核对动作），每批改完与语法门禁一并执行 |
| 10 | 面板在某个入口下无样式/被裁剪 | 主样式只随"调试面板打开"注入；从扩展设置直接打开安装面板时样式尚未注入，浮层以裸 DOM 呈现；已开实例残留还会让再次点击直接早退（表现为"点不开"） | 功能可多入口打开时，**打开动作本身**要补注入样式（幂等）并清理残留实例；浮层挂 `documentElement`、层级用 2147483000 档 |
| 11 | 样式改动始终不生效 | 源头 CSS 里 `color:…!important` 会压掉一切内联样式 | 改视觉前先查源头 CSS 是否含 `!important`；**单一真源**——样式统一放 CSS 层，不在行内写重复值 |
| 12 | 表格某行被读成"有一条金线/金框" | 扩展行整行半透明底色（0.07）在"非扩展行→扩展行"边界形成明暗横带，密集数据中最显眼 | 行级区分优先用**前景元素**（字色/★），不用整行背景色；悬停反馈保持整行均匀、低对比 |
| 13 | 沿事件链猜层级的判定实机失效 | onLose 用 `getParent(2).name` 反猜来源，层级随调用路径漂移（引擎为 onLose 单独 createEvent） | 跨事件关联用**显式标记 + 祖先链遍历**（逐层查挂载字段），不依赖固定层级 |
| 14 | 多名武将的"技能在菜单中整体消失" | 批量脚本的"区间摘除"用**松散终点**（"之后第一个空行/逗号"）定位，在已受损文件上二次操作时该假设失效，误删了 translate 段开头 138 行既有翻译；`_info` 缺失 ⇒ 引擎技能列表不渲染该条（`ui/click`：`if (lib.translate[skill+"_info"])` 为渲染门槛） | ①区间删除必须用**结构化锚点**（唯一行内容）定起止，禁止松散标记；②每次批量增删后做**翻译/键集合 diff**（前后对比，缺了什么一目了然）；③误删恢复：`git show HEAD:<file>` 整段取回、勿凭记忆重写 |
| 15 | 自建浮层内文字重叠、行元素挤成一行 | 引擎全局样式 `div{display:inline-block;position:absolute}`（`layout/default/layout.css:31`，**无 !important**）作用于浮层内所有 div：只复位 position 不够，行内元素仍挤成一行；只靠"打开某个面板时才注入的主 CSS"更会整个缺样式 | 浮层样式**自带独立注入**（幂等、不依赖其它注入时机）：`#浮层 *{position:static!important;box-sizing:border-box}` 通配复位 position，`display` **逐类显式**给（通配 block 会把按钮拉成全宽）；内联样式可覆盖引擎全局（引擎无 !important），但浮层内的版式优先用宿主面板的标准类 |
| 16 | HTML 里 JS 注释变成页面可见文本、页面半崩 | 批量脚本把代码**append 到 `</html>` 之后**：成为 HTML 文本且脚本完全不执行；门禁只扫 `<script>` 标签内内容，覆盖不到 | **禁止向 HTML 文件尾部 append**；代码必须锚定在 `<script>` 块内插入；career.html 已纳入 simulate 内联检查（此前漏收） |
| 17 | "资金/牌技/胜率/底池点击没反应"、五榜内容全部挤在一起 | CSS 选择器**页 id 写错**：`#p-rank` 是「官阶」页，榜单实际在 `#p-board`（排行页）→ `display:none` 规则不匹配 → 五榜视图永久全显（用户看到的"挤在一起"），点击只改 class 无视觉变化 | 写页级 CSS 前**先在浏览器 evaluate `el.closest('#page-id')` 核验归属**；UI 问题先浏览器实测取证（本轮验证法） |
