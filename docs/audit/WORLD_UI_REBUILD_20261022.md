# 池子世界 UI 重建 · 2026-10-22

## 玩家世界入口与世界页

范围：`core/csh_debug.js` 玩家入口与 `games/career.html` 生涯大厅/世界与牌友。版本仍为 4.0.10，无提交、推送或发布；不读取真实玩家存档。

### 真实路径与修改

- 扩展设置「池子世界」→ `lib.cshDebug.openLobby()` → 11 张入口卡 → 原有 shell。入口按「生涯与记录」「休闲与探索」分组，保留全部 11 个入口与原接线。缩小标题与卡片装饰，统一卡片边框/间距/描述字号，移除玩家视图的文字阴影与伪元素装饰；窄屏关闭键固定在首行右侧，音量仍可调。
- 世界动态与人物实际位于「生涯大厅 → 世界与牌友」，此前名为「排行」，不是 debug 目录自身。侧栏减少菜单编号/大字与空白，竖屏六栏目分两行，矮横屏回侧栏；壳右上控制区保留空间。
- 世界页新增姓名/牌风查找、明确的「找到我」「刷新世界」、点击/键盘打开人物档案；筛选保留真实榜单名次，不截断全量人物。动态和世界之最可收起，人物列表统一交给页面纵向滚动。
- 修复 `fillBoard()` 每次重画自动滚动到玩家行，导致进入世界页直接跳过动态/刷新后视口被拖走的问题。现在只有「找到我」主动滚动，切换栏目回到顶部。
- 世界刷新有状态与失败重试；旧异步回包不覆盖新快照。钱包快照更新后同时刷新玩家排名。壳关闭返回世界目录时刷新卡面状态并保留滚动；关闭目录释放观察器。
- 人物与官阶详情：短屏弹窗内滚动、Esc 先关闭详情、恢复打开控件焦点、Tab 留在详情；没有详情时 Esc 经原 `CSHPage.transport.close()` 返回壳。
