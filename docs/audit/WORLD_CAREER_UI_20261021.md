# 池子世界与生涯成就浏览

2026-10-21，本地4.0.9。作者允许必要时重塑UI，本批围绕进入世界与寻找成就目标实施，不改武将机制、不恢复退役势力功能、不发布。

## 玩家世界入口（UI-03，本地完成）

原路径 `cshDebug.openLobby → debug.open → games` 受开发开关拦截，玩家入口显示“池子调试”和资源/技能等开发页签。父面板无键盘关闭和焦点返回，开发浮钮会叠在世界上，每次打开重复添加音乐样式。

`core/csh_debug.js` 复用现有11张入口卡和壳路由，增加玩家视图：标题“池子世界”、隐藏开发页签、独立于开发开关；联机/回放限制保留。面板标记dialog，处理最上层Esc、Tab循环、焦点返回和清理；玩家视图期间收起开发浮钮；音乐样式只安装一次。开发入口仍需自己的开关。

`node tools/probe_world_entry.mjs` 执行真实主题、UIKit、registry、游戏目录和面板，四种窗口/宿主缩放 **84/0**；同组改前HEAD **40/44**。截图与逐项断言：[world-entry](ui/world-entry/results.json)。早期采样发现的12px越界实际处于入场动画中，静止帧未复现，不列为布局缺陷或本批修复。

## 成就浏览（UI-06，本地完成）

原成就墙仅有分类，一次绘制465张小卡；缺少条件搜索、领奖状态筛选与下一目标排序，小数进度被通用整数格式化为0或1。竖屏侧栏占去168px，领取按钮半透明底上的深字对比不足。

`games/career.html` 加入名称/条件/分类搜索、全部/可领取/未完成/已领取筛选、推荐/图鉴顺序，默认先呈现可领目标再按进度推荐未完成目标；每批60枚，“继续查看”可到达全部定义。条件直接呈现在卡内，详情与分类使用原生按钮，小数进度保留；窄屏导航改横排，领取按钮采用实色。筛选只消费最近快照，不因输入请求宿主或更改进度；领奖等待ACK，失败可重试，在途防连点；迟到旧统计不得覆盖新快照。

`node tools/probe_career_achievements.mjs` 在新Chromium配置中加载真实HTML、页面脚本与成就引擎，仅模拟宿主传输，四档布局 **130/0**。覆盖全部465枚可达、20档条件搜索、筛选组合、小数、键盘按钮、连点/失败/重试/成功ACK、旧快照乱序与布局。旧页对照在原有展示断言中失败；旧结构缺少卡key导致后续场景提前结束，不能拿旧页总数与新页总数作等量比较。截图与逐项断言：[career-achievements](ui/career-achievements/results.json)，人工检查竖屏与横屏。

两批均未启动无名杀或安卓，不作为宿主/读屏/触屏实测结论；没有读取玩家存档。成就定义仍为465生涯+80操作，退休表为空。本批只改善消费与交互，未将UI改动计作新增成就内容。宿主领奖持久化错误通道在后续经济审核中另查，不由页面ACK桩证明账本正确。
