# 五项页面流程：账本、领奖、本机记录与行囊

日期：2026-11-03。作者要求一次同步推进五项；本批按独立流程实施、分批并发验证。4.0.14，1946定义/285后台保持；不升版、不推送，成就扩容最后。

## 本批五项完成

1. **生涯账本读取与恢复**（`games/career.html`）。失败不清空上次流水，不把未读到说成没有记录；增加紧凑读取状态和原地重读。新请求/重复回包/卸载相互隔离，异常汇总/条目不替换旧数据。真实空账本和分类无结果分别说明；旧记录未知时间显示“时间未记”，未知结余显示“—”。原流水保存窗口不扩大，移除“不会漏记”的过度承诺。
2. **成就领奖反馈与批次**（`games/achv.html`）。单笔/批量互斥，单笔回包与每批回包只处理一次。用户已转到搜索框时不抢回焦点。剩余数量不下降即停止自动续领并保留手动重试；页面关闭后不再续领或展示迟到成功，传输抛错释放控件。实际奖励/资格/收据仍由原宿主与钱包处理，未增加自动领奖或新增定义。
3. **天下榜本机最佳**（`games/rank.html`）。区分真实零、未知及部分可读；坏JSON/存储拒读不伪装成零。保留本页上次已读最佳，存档代次改变则提示重进，避免混入新档。正常明细按需查看，读取失败提示在默认视图露出，不藏在题名设置里。离线文案不再无条件声称本机记录正常；联网开关、缓存、上报/身份逻辑未改。
4. **行囊文件导入读取**（`games/save.html`）。新文件/手动输入/新的存档操作使旧读取失效，旧失败也不能覆盖新状态。忙碌/恢复/关闭时不采用回包，超过5MB不读取；成功只进入原校验预览，不直接导入。真实File.text路径验证通过，未修改迁移格式或确认流程。
5. **行囊复制恢复**（同页）。复制成功恢复原操作焦点；拒绝时保留完整代码、展开手动复制路径并选中文字。旧剪贴板回包不会覆盖新输入/新保存状态。兼容复制抛错也清理隐藏textarea，不留下脱离页面的焦点或冗余节点。关闭后不更新旧页面。
