## 同类检查范围

- 宿主层覆盖调试、世界、成就反馈和回顾、在线更新、备份、确认框、扩展商城。子页覆盖成就、生涯、行囊、图鉴、金鳞市、天下榜、讨伐录，另查德州、廿一点、斗地主和 UNO 的开局、结算和退出层。检查通知与弹层实际重叠、底部按钮命中、键盘焦点、关闭后恢复。
- 按钮核对常态、选中、禁用、加载和错误。浅纸底深墨字，深色底清楚的正文。普通正文和按钮文字目标 4.5:1，交互边界目标 3:1，触控区 44 CSS px。禁用用明确状态和较弱边框表达，文字继续可读。真实宿主应检查十周年主题、缩放和 Android 横屏。
- 用桌面窗口、915×412 和 640×286 横屏筛查。检查成就入口、交易按钮、更新首末线路、图鉴最后一项、结算下一手和收工的命中。异常时重复关闭再打开。文件与钱包场景做一次正常和一次失败恢复即可，按风险补必要测试。

## 实施顺序

1. 固化线上 4.0.16 与截图设备的版本证据。完成本地升版、纲手替换、皮肤登记与互动接线，保留旧记录键和资产持仓。
2. 重做更新面板的滚动与操作分区。校验时发现完整即结束；局中可主动安装，若选立即重启则明确当前局可能中断；先下载仅保存经过校验的暂存包，提交与重启连续完成，避免旧运行代码读取半套新资源。保证一次提交、正确回滚及强退恢复，然后实测安卓。
3. 统一成就回顾、宿主弹层和四桌结算优先级，修复通知故障路径。用截图复现相同组合，再巡同类页面。
4. 完成图鉴页签、单行交互按钮、浅深两套可读文字及金鳞市交易条；统一调试数值单位换行。继续从玩家常用动作出发控制标题和说明所占空间。
5. 只做必要关口。运行版本与发布清单校验，桌面和安卓各走核心更新、通知及图鉴路径；真实故障仍未复现时保留待验状态。4.0.17 留本地，后续推送由作者决定。
