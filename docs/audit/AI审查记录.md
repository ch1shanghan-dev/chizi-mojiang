# 技能 AI 语义复核

本表与自动结构索引分开维护。当前只对下列条目形成明确结论；其余条目仍是“已索引、待语义复核”，不能由字段数量推断质量。普通名册 99 人的 235 条技能引用、93 位派生魔王及 50 位妖灵的实际技能列表均在 `inventory.json`。父技能的回调索引包含其子技能，数量不能视作独立 AI 函数总数。

## 当前引擎依据

本机 Noname 1.11.6 的 `noname/get/index.js::effect`：先执行 `result.player(player,target)` 与 `result.target(player,target)`，最后按观察者态度分别乘算；`damageEffect(target,source,viewer,nature)` 调用 `get.effect`。因此 `result.target` 应描述目标的收益/损失。`result.player` 或 `chooseTarget` 的直接选择回调则可以采用发动者视角，不能全仓机械替换 `player` 参数。

探针 `tools/probe_skill_ai.mjs` 从当前技能文件 AST 提取真实 `ai` 对象，从本机引擎提取真实 `effect` / `damageEffect` / `recoverEffect` 方法；仅替换玩家、卡牌和宿主上下文。测试不是完整游戏模拟，尚不证明真实发动率、身份推断和所有联动效果。
