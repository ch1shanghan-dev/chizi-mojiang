# 主体优先UI第一批施工记录

日期：2026-10-28。作者明确“开始工作”后实施成就/世界/调试信息骨架第一批。当前版本4.1.0、HEAD c825879；保留既有工作树，未提交、推送或发布。5.0仍是产品重构代号。

## 本批结果

成就页把标题、批领、搜索和状态筛选收成紧凑操作区；分类、排序、详细统计和追踪目标收入可展开区域。侧栏电脑136px、矮横屏104px；卡片标题/条件/奖励/进度保持可读，采用现有皮肤材质和不透明底色。追踪三项目标时主列表不被三张追踪卡挤走，按钮显示追踪数量，展开仍能取消；ESC先收起辅助区域，保留模态/关闭优先级。

世界/调试页保留短标题与独立关闭，音量、皮肤及次要说明归入“设置”，原控件及事件接线继续使用；设置展开/收起可操作，ESC先返回并恢复按钮焦点。世界近况压成紧凑摘要，牌桌/生涯入口、邀约、动态直接可见；结果待保存及行囊恢复入口保留。

生涯页重复CBY提示的根因是body场景类选择器无法匹配挂在documentElement下的壳。新增壳自身data-csh-page状态，按实际根节点匹配；生涯壳不重复显示钱包，关闭留在最右侧独立安全区。没有靠调高层级掩盖重叠。
