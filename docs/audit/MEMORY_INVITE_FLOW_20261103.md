# 回忆册内邀约与撤回

日期：2026-11-03。开发版4.0.14，1946定义/285后台规则保持；本地实施，无提交推送、升版或发布。成就扩容最后。

## 完整玩家流程

世界→人物相识记录→翻开回忆册→邀下一桌→沿用原德州收费确认→取消收费后继续阅读→册页内撤回邀约→再次邀约或返回。

此前回忆册只有邀约，撤回必须离开阅读页到侧栏；已存在的邀约重开册页后也没有明确状态。此次在人物栏内增加按需出现的“撤回邀约”，已有邀约显示“去牌桌”和真实回应/待同桌状态。撤回后保持册页、当前人物及亲历内容，焦点回到主要操作，侧栏状态同步更新。

## 实现边界

- `core/csh_world_view.js::openMemory` 使用原 `inviteNext/cancelInvite/storylines`；不新增存档、人物对局事实或交易，不改原收费、座位优先与邀约消耗规则。
- 原邀约主按钮继续进入德州原生收费确认，未增加自动扣款或跳过确认。邀约仅表示带入合适时优先同桌，不保证任何赌资下都能入座。
- 重新打开册页时从当前邀约真源恢复状态；失败/恢复锁下不假装撤回成功。异常显示中性可重试提示，不露内部报错。
- 被关闭或替换的旧册页按钮不能再修改当前邀约。处理人物操作时不把焦点送进已隐藏的侧栏；返回仍保持原相识记录/焦点逻辑。
- 主要内容仍是人物、亲历与片段；撤回只在有真实待处理邀约时出现，44px热区，横屏窄栏可换行。不新增常驻统计或调试信息。
