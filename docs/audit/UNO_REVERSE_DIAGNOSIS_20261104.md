## 已复现

`botChooseCard`将reverse和skip/draw2/wild4同列攻击。当反转后的下家仅1–2张时，评分给-30，主动优先出反转；而`applyEffect`在3人以上只改变方向，并不跳过反转后的下家。由此把立即出牌机会送给最接近获胜的人。

最小公开局面：当前颜色红，自己有红反转、红6、蓝9；正常方向下家4张，反方向下家1张。原策略选择红反转，普通红6本可先让4张者行动。受控反例将反方向下家最后一张设为红3，实际合法play后该玩家当场获胜；换成其他最后牌策略选择仍相同，算法只使用公开张数。该构造证明一个可发生的坏分支，并不宣称未知最后牌必然能出。

`tools/probe_uno_reverse_diagnosis_20261104.mjs`在三人/四人、两个方向4/4复现，其他玩家手牌代理仅允许访问length时仍可选择，未出现偷看暗牌。结果位于D:/CodexWork/chizi-mojiang/work/uno-reverse-diagnosis-20261104/diagnosis.json。无C盘测试产物。

## 建议的最小修复

1. 保留双人反转等价跳过，以及现有可靠接续终局优先；多人反转按“下一个真实行动者”评估，不因把短手玩家叫上来而奖励攻击分。
2. 多人反转若把正常方向的短手威胁转给另一名较长手玩家，可小幅鼓励；反转后的下家短手则提高风险评分。仅依据公开剩余张数、方向、出局状态及自己手牌，不推测最后牌颜色。
3. 不能简单将reverse从attack移除而沿用数字牌公式：Number('reverse')会得到NaN。需有明确反转基础评分，维持数值有限和稳定排序。
4. 样本覆盖2–4人/双向/有出局座位/当前手收尾/反转避开短手与反转送短手/颜色合法性；同公开计数不同暗牌选择不变；旧取消托管/回合与销毁守卫必要回归。
5. `probe_minigame_planning.mjs`有“UNO reverse assesses actual previous-seat target”旧断言，在逆向下家1张时明确期待reverse。这条目前奖励同一错误；修复时应重写为真实避险反例并保留方向断言，不能盲目保持旧期望。
