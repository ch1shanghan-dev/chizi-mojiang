本批已应用安装目录，本地版本仍为 **4.0.9**，没有提交、推送或发布。未读取或改写玩家真实存档。

## 已复现的路径

旧 `csh_migrate` 的 `lsSet/lsPut/lsDel/cfgSet` 吞掉异常。导入在自动备份写失败、部分数据写失败、宿主配置尚未完成时仍返回成功；回滚和重置同样缺少完成确认。旧重置没有按注册表清全设置与键族，`bounty` 还误走 LS 删除，未删除真实 config 数据。`collect()` 对字符串后端也做 JSON 解析，使原始皮肤字符串导出为 null。

宿主依据是本机 `<NONAME_ROOT>`：

- `noname/game/index.js:9301` 的 `saveConfig` 调用 `save(...).then(callback)`，没有返回内部 Promise。
- `noname/util/config.js:51` 的 `save`：有 IDB 时使用 `config` object store；没有 IDB 时合并 `${lib.configprefix}config` 的 JSON，再写回同一键。
- `noname/game/index.js:8867` 的 `putDB` 在 request success 时兑现，早于事务 complete。request success 后事务仍能 abort；本批用真实 Chromium 再现此路径。

## 本批修改

`core/csh_migrate.js` 构造完整写入计划，在覆盖前严格保存本机原始恢复凭据 `csh_migrate_recovery`。凭据保存原值和“键不存在”的状态，不能用经过清洗、合并的便携备份代替。

LS 写入和删除均读回确认。IDB 配置先读取原值，再将整批写入/删除放入同一事务，收到 complete 后更新 `lib.config`。没有 IDB 时合并真实宿主 config 键，保留无关设置，拒绝覆盖格式损坏的宿主配置；该键原来不存在时，失败恢复会删除它。

覆盖失败会尝试恢复原值，包括已写入的数据、新增键和 config。恢复自身失败时保留凭据，拒绝后续导入、回滚、重置与导出；重试先完成恢复。超时会请求 abort，但终态未确认时保留事务锁和凭据，迟到完成不能被当作“从未写入”。只有两边完成且恢复凭据删除成功后才回成功。

回滚恢复缺失的 config、普通字符串、组合键和 BGM 通配键；CDK 在导入及普通回滚时继续只并集，重置仍按原设计清空。重置从实际 `KEY_DEFS` 派生范围，同时清理历史镜像与备份，配置项真正删除而非保存 null。写前刷新钱包并检查余额落盘，防止用旧余额做备份；刷新取消钱包防抖，重置后旧定时器不会重新创建钱包。

迁移成功/补偿恢复/重置接入世界线程的只读 `world.reloadSave()`，按当前 LS 刷新内存，不通过 `importRaw()` 再写一次，删除的世界不会被旧内存复活。保留原市场检查点等待/便携扁平化、导出前 flush、职业奖励凭据与钱包重载契约。

`core/csh_shell.js` 的回滚/重置改为等待异步结果再 ACK，保留原始 req；新增恢复桥和清单中的恢复状态。异步回包同时绑定原iframe、文档与壳世代，旧页面完成不能误回新页面的同号请求。`games/save.html` 提供始终可用的“恢复未完成操作”按钮，显示宿主具体失败原因和重新进入页面后的恢复提示。恢复失败明确要求先恢复，再使用其他功能。桥等待提高到 20 秒；原双重确认保留。新按钮 44px，真实浏览器指针可点击。

并行交叉审核又复现并补修四类问题：成功重置后真实beforeunload/pagehide会把旧钱包写回来；旧iframe迁移ACK误落新iframe；自动备份/导出吞读取异常生成不完整备份；最终钱包/世界重载吞读取错误，用默认或旧内存覆盖已经导入的数据。现备份/导出/键族枚举严格读取，读取或JSON解析失败即中止；提交/补偿恢复在清凭据前严格读齐钱包/官阶/任务/世界，再采用同一批快照。wallet.reloadSave(snapshot,{memoryOnly:true})与world.reloadSave(snapshot)不做第二次容错读盘、不额外签名/补流水或推进世界。内存采用失败也在事务恢复范围内。成功重置采用默认内存，卸载只可能保存新默认值，不复活旧余额、链、领奖凭据、官阶与任务。

恢复凭据列入 `EXCLUDED`，不导出、不随普通重置删除；恢复成功才清除。schema 自检不再向真实宿主配置写临时键。

## 保留的边界与下一步

本批提供可确认的迁移写入结果和可重试的恢复路径，**没有建立全扩展写锁**。恢复失败且凭据尚存时，迁移自身拒绝新的破坏性操作，但其他模块的普通钱包/世界/市场写入口尚未统一冻结。若这时继续游戏或其他功能，再恢复可能覆盖那段时间的新变化；页面明确提示先恢复。后续应独立审查并接入跨模块恢复守卫，不能称此问题已全部解决。

没有对任意并发宿主写入、真实断电/进程强杀、安卓或旧 WebView 作保证；当前事务故障和重启为隔离验证。必要钱包/世界内存采用失败不再按成功处理，恢复完成前保留凭据。恢复凭据损坏时保留原数据并拒绝继续覆盖；不要手工删除凭据当作恢复。
