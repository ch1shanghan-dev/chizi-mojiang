覆盖主/次/危险按钮、页签选中、排序、输入/选择、开关、浮动入口、技能方案、卡牌与技能详情、输入确认、统计导入导出、危险确认、台词管理与空态。保留已有直接监听，统计原委托入口转换为原生按钮；非原生控件补键盘语义。图片不截获指针；缺图保留文字和原样式，按下下沉、焦点、禁用与减少动态偏好均有处理。

小屏补修：关闭键不再叠字、皮肤选择不挤出首行、按钮端盖留白缩减以容纳原动作标签；统计和互动面板打开时隐藏本扩展悬浮入口，关闭后恢复，避免压住正文。没有给宿主或其他扩展的全局button套样式。
