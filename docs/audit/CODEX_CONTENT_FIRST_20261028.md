# 妖灵图鉴：横屏主体与可展开名录

日期2026-10-28。本地4.1.0不变、未提交/推送/发布。本节点推进现役待办U01的一页，不宣称全局UI、图鉴故事或批量礼物已完成。施工前1387文件摘要与文本备份在工作区work/codex-layout，玩家存档和生产服务未访问。

## 复现与根因

打开池子世界→妖灵图鉴→入场确认，窗口640×286。原max-width:720px规则将名录、立绘、资料全部上下堆叠，readable-ui里的gitem宽100%又使水平名录单项占满一整排；立绘只剩约47像素横条，资料可见约70.8像素。915×412虽未堆叠，常驻196像素名录与头部也使档案主体面积仅60.3%。这是实际完整宿主浏览器的可复现几何/交互问题，不是对截图的推测。

## 已修改

- 1000像素及以下名录按需展开，选择后收起，50人列表/置顶与原排序保留；电脑继续常驻名录，收窄辅助区域。展开内容处于普通页面布局，不使用遮挡主体的模态蒙层。
- 横屏人物与资料左右分栏，640×286同样如此；竖屏保留上下兜底。照片继续沿原图路径与裁切策略，无人物资源替换。
- 头部为一条44像素短操作行，去掉副标题/统计胶囊装饰与低信息页脚；统计仍展示已讨/总讨伐，完整50位名录可访问。钱包和宿主关闭按钮独立避让。
- 互动/礼物/置顶保持约44像素点击高度，长公开题壁与简介可换行，资料为独立滚动区。没有缩小正文字号以凑面积。
- 名录按钮提供aria-controls/expanded；展开焦点到当前人物，选择或Esc收起后回到按钮，左右方向键翻人继续可用。切换人物回到资料顶部，避免停在上一个人的底部。空态没有无用名录入口。
