# UNO多人反转方向策略修复

日期：2026-11-04。接续[修前诊断](UNO_REVERSE_DIAGNOSIS_20261104.md)，本轮已实施到正式安装页。版本4.0.14不变，不提交推送、不扩容成就；未增加+4质疑或改动牌局规则/奖励。

## 改动

多人局的反转只改变出牌方向，不能像跳过一样奖励“即将轮到一张手牌者”。`botChooseCard`现为3人以上反转保留明确有限基础分：反转后的行动者只剩1–2张时提高风险；反转能避开正常方向短手者且反方向较安全时予以鼓励。只依据公开方向、出局标记、剩余张数与自己的牌，不猜最后牌颜色。双人反转的额外行动、原两步收尾、末张立即胜利、合法出牌与托管共用策略均保留。

原`probe_minigame_planning.mjs`曾明确期望将前座1张者叫上来的reverse。该断言现改为不邀请前座短手，并由新实际play反例验证方向与后果，不为了保持错误期望而保留缺陷。修前诊断探针新增`--source-file`与`--expect-reproduced`，可单独重现原始反例；默认仅报告当前状态，不把修复后反例消失报成故障。
