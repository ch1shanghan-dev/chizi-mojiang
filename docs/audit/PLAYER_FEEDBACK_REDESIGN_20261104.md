## 3. 妖灵助战2.0：有回报、有个性、不挤牌桌

### 3.1 模式与奖励

- 玩家选择“妖灵助战”后，开场清楚显示所选妖灵、核心帮助和本场基础奖励，正常结束后兑现。**推荐沿用当前该模式配置的普通胜/负基础奖励**，不因为玩家用了助战就取消游玩回报；具体金额读唯一配置，不另写一组散落常量。
- 胜利有胜利奖励，失败有正常完局的参与回报；不按妖灵伤害、重复治疗次数或存活与否无限叠钱。羁绊/共同经历可作为独立叙事进展。
- 奖励分类为助战场，独立保存；是否计某类成就按条件逐条声明。普通场战绩与需要无辅助达成的战术条件保留原含义，不把助战胜利冒充无辅助胜利。
- 奖励、助战胜负、唯一终局凭据和待补流水同次严格保存，成功ACK后才显示到账；拒写留待保存结果，重开/导入/重复game.over不能重复发。到账以实际余额空间为准，不显示理论全额冒充实得。
- 提前退出、回放、观战、控制切换、非布尔终局不按自然完局发奖。若妖灵因引擎不兼容始终未加入但发生真实自然完局，应回到可证明的普通结算路径，不能沿用目前“预约了但未入场即整场没奖励”的体验。
- 不把妖灵阵亡等同主人失败；先前确有共同作战即保留其贡献。主人阵亡后的阵营结局依原生身份裁定，不能单看妖灵是否活着。

### 3.2 默认推荐改为“随行契灵”，实体扩席保留为兼容可选

**优先原型A：妖灵挂靠主人，不新增一个常规武将席位。** 以立绘角标/小印记表示随行，在原生事件上执行有限助战。这样不用把第9个人硬挤进8人身份桌，也避免额外忠反身份改变胜负与轮次。

- 妖灵自身状态区分“可助战/休整/本局额度用尽”，不伪造额外血条与阵亡。若该形态采用灵力/受创机制，要给完整独立规则，不能把实体死亡文字原样移植。
- **原型B：实体同伴席位**仅在能正常排版的宿主/人数启用；保留其实际回合、阵亡与复活，不删除原生死亡节点、不手改座次假装退场。妖灵死后退出活人行动链，实体复活也不重置已用额度。
- 两种形态在开局前选择并明确，不能战斗中静默切换、借换形态刷新次数。旧实体模式会话继续旧规则至终局；新模式需独立兼容与结算验证。
- 支持图鉴“设为随行”与开场查看；随机作为可选玩法。未相识/未解锁条目可看获取线索，不把所有妖灵自动视为已结契。

### 3.3 牌桌呈现与交互

- 桌面常驻只保留“妖灵名 · 当前状态”和1～3个可辨认的剩余能力图标；不常驻长说明、不压住手牌、响应按钮、身份标记或原生提示。
- 主人头像旁是入口，小屏横屏按安全区收紧；点开才显示短横向抽屉：头像/姓名 → 本局核心帮助 → 可用次数/下次触发 → 记录。首屏不出现调试信息。
- 被动触发用一次短动效和一行说明；多次事件合并，避免每次摸牌刷气泡。玩家出牌/响应时不弹强制模态框。
- 固定宽高占用预算，1365×768、915×412、640×286检查真实遮挡、实际点击和焦点；正文≥12px、操作≥44px。竖向仅横屏引导。
- 阵亡/休整/额度耗尽时自动收起“可使用”样式，不能残留亮按钮；详情明示实际原因和何时恢复，不用一大段同时解释所有异常。

### 3.4 50名妖灵的区别：先锁定方向，再做数值

每名至少一个独有触发/操作/适配玩法，差异不能只是名字、颜色或同效果+1/-1。采用有限预算：一个核心特性，最多一个有辨识度的条件变化；不再人均叠同样三套强帮助。主动项须可拒绝，涉及未知信息时只用公开信息或主人的合法信息。皮肤与付费赠礼不提供额外战力。

## 4. 多皮肤：入口先就绪，素材由作者提供

- 可行。图鉴人物页增加低频“装扮”入口，已有头像/立绘点击也能进入。支持每名任意多套配置，不硬编码每人必须3套或4套。
- 建议素材方向为经典、日常、战装、仪礼/节庆；名称和实际套数由作者素材决定。初期只显示现有经典形象，其他用一处“更多装扮待提供”说明，不铺满空卡片假装已有皮肤。
- 每套具有稳定妖灵ID+皮肤ID，静态主图、头像、封面和可选动态/音声分别声明；不复制多份相同大图。通过逻辑ID同时覆盖图鉴、随行标记、实体助战别名及其他授权展示位置，避免同一妖灵跨页不同装。
- 区分“本人选择的装扮”和“剧情临时形象”；缺图、未下载、损坏、撤回素材、旧皮肤ID无效时回经典，不出现空白/404或重置关系。
- 换装纯外观：不刷新次数、不复活、不改体力、不增加奖励/好感，不改任何武将立绘。战斗中允许的即时换图也不能重建角色对象。
- 入口、预览、切换/恢复经典、跨页保持、迁移保全先实施；作者提供皮肤后再接实际文件与裁切。离线经典始终可用，不强迫登录/联网。
- 素材交付说明后续给作者一页简表：妖灵名、皮肤名、原图、可选头像、是否允许裁切/动效；用户不必手写JSON或懂资源路径。

## 5. 图鉴的SLG×GAL：由名录升级为有策略与人物因果的世界

### 5.1 主体验闭环

相遇/讨伐/事件认识 → 选择相处方式 → 共同战斗或经营决策 → 产生真实记忆和关系变化 → 解锁新的事件/协作 → 地区与人物反过来响应玩家。赠礼只是一种表达，不是全系统唯一按钮。

**SLG层要有真实取舍**：伙伴专长、队伍/岗位配置、地域资源和局势、行动成本、收益风险、情报与外交、长期阵营/据点成长；不能仅把几个倒计时派遣任务称为SLG。

**GAL层要有可持续的人物关系**：独立语气、价值偏好、关系边界、多个关系阶段、分支和回访、共同经历的准确引用。不要把所有人写成换名字的同一套好感台词，也不把最高关系限制为同一种恋爱路线。

### 5.2 角色页横屏构图

- 左侧紧凑名录，可搜索/筛选/收藏，默认不吞掉一半屏幕；小横屏可收起。
- 中央主体为人物立绘、简短身份与当前一段回应，占最大视觉面积。姓名标题紧凑，长背景文字进入档案。
- 右侧只放当前关系阶段、本次事件/可行动项与简明成本。完整能力、共同经历、皮肤、档案分别按需打开，不堆在立绘下面形成一条超长页面。
- 主入口建议“相处 / 共同行动 / 记忆 / 档案”，装扮为人物内入口；未相识角色展示线索，避免提前剧透关系分支和秘密条件。

### 5.3 人物关系与叙事

- 初识、熟悉、信任、亲密/知己/盟友、结契等为有情境的关系阶段；用喜好、信任、共同经历承载区别，不再只有一个可用金钱直冲的数值。
- 对话可选闲谈、近期经历、询问、邀约、赠礼、约定与告别，开放项取决于真实条件。有限日课不变成强迫每天签到刷一句；玩家错过天数不被惩罚式掉关系。
- 角色能拒绝不合适的礼物/邀约，并说明当下理由，不让玩家反复点击无效按钮。恋爱、友情、合作路线保持选择，不替玩家自动作承诺。
- 记忆有来源、参与者、已知时间与是否已看；不能把世界AI自己发生的事情写成和玩家一起经历。旧档未知时间留白。
- 每人需要人物语气表、偏好/禁忌、阶段事件树、至少一条可闭环的角色线、回访变化与去重规则。长线可共享事件结构，但关键选择/后果/台词必须独有。
- 关系变化只显示对玩家有用的文字与原因；内部权重、概率种子、回执、调试字段不出现在角色页。

### 5.4 SLG策略层分期但保留完整远景

1. **伙伴与营地**：随行/岗位专长、共同行动选择、经营资源用途；行动前看到成本、预计时长/风险和可取消边界。伙伴在做什么可查，不让同一个角色同时在三个地方。
2. **地区与势力**：有持久状态的地区、据点、资源路线、情报、势力关系与事件；玩家可以外交、交易、防守或介入冲突。地区变化产生角色事件，角色立场影响行动选择。
3. **长期战略与叙事联动**：阵营目标、领地发展、可逆失败与恢复、伙伴分歧及解决、支线结局回访。SLG成败影响关系场景，人物决策也影响战略，二者不能是两个互不相干的菜单。

派遣/营地/地图是新增玩法提案，需独立经济、离线时间、失败和旧档规范，不能在没有模型时直接上线大量奖励。默认单机离线可玩，服务器不是基本关系/剧情的前置条件。已有原生无名杀对局保留主入口，不被强制经营盖住。

## 6. 德州：先确定桌制，再重做带入、补码与退隐

### 6.1 推荐桌制与区别

资金档、桌型、AI牌技和角色财富是四件事，分别定义：资金档决定风险金额，桌型决定盲注/带入范围/是否补码，牌技来自真实世界人物，财富决定是否负担得起。不能只把换筹码颜色叫不同桌子，也不恢复玩家AI难度按钮。

| 桌型提案 | 推荐桌规 | 玩家体感 |
| --- | --- | --- |
| 常规现金桌 | 固定盲注、明确最小/最大带入，可在两手之间补码 | 可持续同桌，输一份带入不等于破产 |
| 深筹桌 | 同资金层更深的带入BB范围、明确更大风险与更长决策空间 | 深筹博弈，不能只换皮 |
| 豪赌桌 | 按实际资金资格准入，桌限允许更宽筹码深度；有承担风险意愿的AI可全额投入 | 高风险人物与资金故事，不能无资金凭空给2～5倍 |
| 升盲竞赛桌 | 清楚公布升盲与是否允许重入的时间窗口，窗口后不再补码 | 保留当前升盲玩法的明确归属，不伪装固定盲注现金桌 |

桌名是候选。开场只显示盲注、本人带入与BB数、可补码规则/费用、关键桌限；长牌规在按需说明中。桌面常驻自己的筹码、底池、行动与当前盲注，其他背景资金仅查看人物时呈现。

- 盲注从桌子配置取，不由本次玩家临时带入额反推。BB范围先统一评估，例如常规40～100BB、深筹100～250BB为候选；金额再映射到现有资金档，不先硬写新金额。
- 当前最低带入200却最低BB20的10BB浅筹问题要专门修；升盲桌的基础深度也应一致、如实显示。
- 资金/筹码统一整数计算，前注、抽水、可争夺底池、边池与补码不混为同一笔费用。旧场按旧桌规结束，新桌规仅新会话采用。

### 6.2 AI带入：允许全额，但由人物自己决定

- 取消统一30%/60%作为所有牌手的唯一上限逻辑，改为桌限内、本人可支配资金内的自主带入。
- 稳健者分份保留周转，常客按习惯筹码深度，冒险者愿意更深，追损者可能加大投入但不能无上限；结合既有情绪/疲劳/宿敌关系，避免靠故意变蠢制造破产。
- **全额带入是一种合法选择**：只有全部资金在该桌准入/上限允许范围内且本人愿意承担时才用。富豪不能在低额桌把几千万压进来；穷AI也不能因固定百分比卡在够最低钱却永远坐不了桌的灰区。
- 入座时锁定本次带入报价/人物资金来源；同一次邀请读状态不能再次随机金额，等待过久资金变化须重新确认。玩家不必管理所有AI的资产滑杆。

### 6.3 追加反馈：桌上打空后补码重新上桌（优先纳入）

**推荐采用。这比每次都全额带入更自然，也能把持续同桌与退隐串起来。**

1. 当前手彻底完成、边池分配和必要结算接受后，零筹码AI先显示“考虑补码/离桌”；不能在尚有待处理全押或未分边池时复活参与本手。
2. 可用场外资金足够、桌规允许、本人愿意继续时，按桌限决定追加金额；资金不足、疲劳过高或不想追损则离桌/休整。
3. 常规桌可补码；竞赛桌仅在预先公布的重入窗口允许。玩家知道当前桌规，不能AI有无限重入特权而玩家不知情；玩家补码交互与公平性一起设计，若本批只做AI则必须明确现有玩家再入场规则。
4. 补码来自该AI的**真实剩余可用资金**，不是系统无中生有加一份。初始带入、追加、退回、场外余额与桌上余额须对应同一资金快照，不能拿尚未结算的旧fund反复当可用额度。
5. 概念核对式：可用场外余额＝本场初始真实资金－累计投入＋已实际取回；桌上筹码单独记。终局世界净变动＝最终取回总额－累计投入。具体对接已有收益/抽水规则时再逐项核准，不能只在页面chips+=n。
6. 每次追加有独立会话内序号和幂等凭据，保存/世界资金意图接受后才重新激活席位；拒写可重试、重复点击/ACK不多加一次、换档旧回包不得补进新桌。
7. AI的投入预算、重入次数/意愿与休整由角色和桌规决定，防止一手一补的机械循环；候选限制需要仿真，不先武断定“所有AI只许3次”。
8. 若仍有其他牌手，允许符合规则的原座下一手回来；按钮和盲注计算按下一手实际活跃人数重算，不中途篡改本手庄位。全桌只剩一人时先走明确的手间补码/结束决策，不能既宣布冠军又让旧AI立即插回。
9. 真人退出/筹码归零终止当前会话或选择合法再入场时，AI不继续在已关闭旧桌补码；旧定时器、已离桌AI和延迟重入回调均作废。
10. 补码失败、关闭页面、导入存档、AI世界资金变化、重复结果恢复都纳入资金关键验收。未保存追加不能被当作“已坐回”。

### 6.4 退隐、离桌和复出

- 桌上筹码归零 → 尝试补码或离桌；不直接退隐。
- 世界可用资金仍足够但不愿继续 → 休整/换桌，是人物选择。
- 世界总资金低于最低可玩门槛且没有仍在其他会话锁定的合法资金 → 按真实经济结果触发退隐；必须等结算接受。
- 未决结果期间不得既退隐补助又补码、同时占多桌双花。常规世界事件若影响同一资产，也须使用锁定/结算保护。
- 复出资金的来源与旧3天规则一并评估，不伪装“原筹码回来了”；防反复输光领取补助套利，也不强迫破产者永久删号。
- 保留人物历史：曾经同桌、被谁击败、是否复出；不能把任何输给AI或退隐都归因玩家。记录与关系叙述须依真实事件。

## 7. 成就通知：给够阅读时间，多个能逐个看

- 默认普通8秒、稀有12秒为候选，支持较短/舒缓/手动关闭；长文字按阅读量适度延长。重要的是阅读控制，不是单纯把2400改成8000。
- 同时只显示一张主卡，带“本批第2/8项 · 未读6项”；上一项/下一项、查看详情、收纳各有明确语义。不要多个覆盖在同一位置抢点击。
- 鼠标悬停、键盘焦点进入、触摸展开后暂停当前卡计时；打开任一详情即暂停整批队列。返回同一条，读过后可标已读，再下一条，不因30秒到了丢剩余待看项。
- 小横屏保留44px实际触控按钮；卡片正文简短、详情展开后主体可滚动，不把下一条按钮藏在不可发现的布局中。
- 在世界/生涯常驻一个轻量“成就·未读N”入口。收纳关闭动画但保留未读，不等于全部已读；玩家可以随时再开。
- 回顾支持按批次、解锁/领奖、池子/生涯筛选；每项可独立展开，上一/下一条与返回列表保持位置。详情包含名称、条件、当前已知记录、实际达成时间、奖励是否待领/已领。
- “已解锁”不能写成“已到账”；查看详情不自动领奖。奖励仍走原凭据和原手动流程，通知消失与奖励无关。
- 当前本次200项临时历史不足以承载该体验。规划跨重启的轻量未读索引/分页历史，与原成就真源关联；到数量预算时归档，不能默默删尚未阅读项。通知存储异常不影响已接受的成就/奖励，后续可由真源重建可证明记录，旧未知日期不补造。
- 大批量只播一次或有限几次提示音；保留静音、减少动效、对局确认期间暂缓、换档清理旧通知等现有保护。阅读过程不抢出牌焦点，不自动暂停原生牌局，模态打开由玩家主动决定。
