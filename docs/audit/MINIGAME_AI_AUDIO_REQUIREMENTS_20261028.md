# 小游戏AI、托管与声音升级（作者追加，2026-10-28）

作者直接要求：德州不提供玩家调节难度，世界拟真优先；所有小游戏的AI逻辑、托管等和音效继续升级。该要求覆盖上批“轻松/标准/高手”设计。版本4.1.0不变，不自动提交/推送/发布；普通武将战斗AI仍暂停。

范围：德州、斗地主、UNO、廿一点的实际决策与已有托管；共用音效覆盖所有使用总线的小游戏/金鳞市/图鉴等入口。金鳞市不是对手牌桌、图鉴不是AI对局，不编造不存在的机器人。原游戏收费/奖励/存档与离线保障保留。

验收方向：只使用本人牌和公开信息；世界角色牌技、性格、心态、疲劳/经验影响能力与表现，不让玩家选择AI输赢强度，不偷偷改变发牌。廿一点庄家按公开桌规，不能为拟真篡改S17/H17或赔付。托管随时可取消，取消/换局/关闭后的迟到回调不得行动；不擅自开启托管、自动加注带入、自动开下一场或替玩家消费。

声音要区分纸张、筹码、行动、控制效果、关键胜负，减少刺耳电子音与同时叠响；保留每游戏开关/全局音量/默认静音偏好和永久离线。停止/退出/后台后清理声音；验证配方、节点与真实浏览器音频路径，不能将程序测试当作主观听感已获作者认可。

分批施工：先去德州难度与世界状态接入，修复四款实际规则/策略和托管生命周期，升级共用音效；再继续更深的组合规划、世界角色差异、自然完整局与实体设备听感。每批记录已完成项与未验证项。

2026-10-28第二批已实现有界本人组牌/续牌、公开记忆和快速接管；详见[本批记录](MINIGAME_PLANNING_20261028.md)。高级对手范围、桌规匹配与实体设备仍是未完成项，原验收方向保留。
