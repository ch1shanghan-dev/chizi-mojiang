## 检查发现

生涯493 + 池子1380 = 1873条唯一ID，退休0。1873是定义数，自然实战合格数仍未知，距10000原始定义名义差额8127。

发现4组相同豪赌连胜条件：gstreak2_2/3/5/8与gmstreak_2/3/5/8。核对core/csh_achv.js两处tier，均读取gambleBestStreak，阈值相同，奖励不同。列为后续兼容内容设计项，保留旧ID、已领与奖励，不自动退休或重复算作特色成果。

16组跨人物共用指标进入语义复核，如累计得牌、杀伤害、护甲。共用指标并不直接等于重复，需结合人物技能和自然过程逐人审查。当前每人13条中9条指标阶梯、3条胜场、1条同局挑战；数量达标不能代替特色审查。

生涯稀有度和两类hidden字段尚缺完整契约，已写入机器报告，未批量填默认值伪称完成。

## 使用

在扩展根目录运行（输出建议放扩展目录外）：

```powershell
node tools/audit_achievement_quality.mjs --out <扩展目录之外的输出目录>
node tools/probe_achievement_quality.mjs
```

audit退出码0表示结构检查通过，1为结构错误，2为环境/加载错误；人工复核项不自动阻断。报告保存四个源文件SHA256，可对应后续内容批次。
