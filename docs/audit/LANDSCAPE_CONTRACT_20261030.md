# 纯横屏修复与后续美术工作 · 2026-10-30

## 原因与修复

用户截图指出样板在约360像素宽的竖向预览中仍显示成就操作界面，搜索/筛选换行、列表挤压。前次仅验证三个横屏尺寸，没有验证“竖向窗口不得呈现可操作成就界面”，属于样板实现及交付验收遗漏。

原链接已原地更新：只在横屏且宽度至少600px时显示成就主体。竖向/过窄预览仅显示横向查看引导，可点击全屏；无法全屏时明确提示拉宽或独立窗口查看。不是新增竖屏玩法，不缩小文字凑屏；横屏恢复保留分类与筛选。横屏断点显式带orientation:landscape。

检查正式目录发现全部11页landscape:false，导致既有壳checkOrientation直接返回，横屏提示形同关闭。core/csh_registry.js现统一landscape:true，并在既有selfTest加入纯横屏约束。没有改动壳玩法、费用/结算/带入/奖励、钱包和成就定义。图鉴/金鳞市尚有历史竖向兜底CSS，但正式壳现在覆盖非横屏展示；data-csh-palette="portrait"是人物配色名，不是屏幕方向，不误改此标识。本批未批量重构历史CSS或改宿主旋转机制。
