# 好感度直接入口的恢复守卫

2026-10-22，v4.0.10发布后继续本地维护，未包含在已发布ZIP中；旧武将AI仍暂停。

## 缺口与修复

壳消息已有恢复保护，但同源页面可直接调用 `lib.cshAffection`。恢复凭据存在、迁移busy/pending或恢复凭据读取失败时，直接聊天/送礼/讨伐记录/同桌记录仍会改好感、每日标记或台词收集；结契和送礼还可能走到钱包扣款调用。

`core/csh_affection.js` 现在优先复用真钱包的 `saveGuard.blocked()`。钱包守卫尚未安装时按已有持久凭据和迁移状态保护；读取/守卫异常一律拒绝。保护加入增长、每日状态、台词收集、回礼、互动、送礼、结契、重置和可增长状态入口，发生变更或经济调用前返回原API适用的失败类型。

恢复期间get/list/summary等读取仍可用，读取台词也可返回文本，但不偷偷记录“已听”。恢复完成后未执行的互动可以正常重试；没有提前消耗每日次数。平时数值、礼价、门槛和回礼概率保持原样。
