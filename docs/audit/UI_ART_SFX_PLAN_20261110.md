# UI 美术与音效优化 · 工作方案（2026-11-10）

> 作者指令：**音效与美术只优化 UI 层**；**UI 美术必须是生成的位图，不许用 CSS 画**；32 位角色立绘不管；其余内容不碰。本文是施工方案，暂不动产品代码。

## 0. 范围与红线

**做**
- 四款牌桌的桌面、桌边、牌背、筹码、下注区/底池、结算层纹理
- 面板底板（弹窗/卡片/抽屉）、按钮底板（补小号与按下态）、图标（补齐成套）
- 主要功能页背景（世界入口、成就、生涯、行囊、官阶、图鉴、金鳞市、天下榜、讨伐录）与装饰纹样、光效贴图
- 音效：修 8 个静默调用名 + 七项听感体系调整

**不做**
- 32 位未提供素材的妖灵立绘；已接入的 18 位 / 70 套皮肤不动
- 技能演出、战斗特效（属效果层，不在 UI）
- 规则、AI、资金、结算数值、任何存档键

**红线（沿用 `docs/art-direction.md` 与 `ART_ASSET_MANIFEST` 既有纪律）**
1. **不烘焙文字与数字**：所有文案、牌值、金额仍是 DOM，图片只做材质与底板
2. 图片 `pointer-events:none`，不遮挡点击；可点区域仍由 DOM 承担，触控 ≥44px
3. **失败回退到现有 CSS 渐变**：图片缺失/解码失败时页面必须照常可用，不白屏不阻塞
4. 不引入第三方素材：全部由 ImageGen 原创生成，prompt 与产物留档
5. 体积预算：单张 ≤200 KB，本方案合计 **≤8 MB**（当前扩展 155 MB）

## 4. 生成与加工流水线

1. **定风格**：先只做 1 张「德州桌布」的 3 个方向（A 旧绒布压金线 / B 硬朗几何 / C 水墨纸感），你选一个再批量。
2. **批量生成**：按清单逐张 ImageGen，prompt 内固定色板与光照词，保证同批次一致；每张存原始大图到 `D:\CodexWork\chizi-mojiang\temp\art-v2\raw\`。
3. **加工**：PIL —— 裁切对齐 → 缩放到目标尺寸 → 暗角/对比微调 → 导出 webP q88（透明图 `lossless=False, alpha=True`）→ 生成九宫格切片。
4. **归档**：产物进仓库 `image/ui/art-v2/<模块>/`，同时在 `docs/audit/ART_ASSET_MANIFEST.csv` 追加行（列不变），保留 prompt 到 `ART_GENERATION_BRIEFS.md`。
5. **接入**：CSS 侧统一 `--csh-art: url(...)` + `background-image: var(--csh-art, none)`，**旧渐变保留为 fallback 的第二层**；`<img>` 侧沿用 `onerror` 自移除。

## 5. 音效方案

### P0 · 修真实缺陷（8 个调用名被静默丢弃）

`resolveName()` 在 `RECIPES` 与 `ALIAS` 都查不到就 `return false`，调用点又统一 `try/catch`，所以**一直是静音**：

- `uno.draw` / `uno.reverse` / `uno.skip` / `uno.wild` / `uno.penalty`（UNO 摸牌、反转、跳过、变色、罚牌）
- `ddz.straight` / `ddz.rocket` / `ddz.plane`（斗地主顺子、王炸、飞机）

修法：**补 8 条配方**（不是登记别名，因为要各自有辨识度），并把 `lastError` 暴露到调试面板一行，避免以后再静默。

### P1 · 听感体系

| 问题 | 现状 | 调整 |
|---|---|---|
| 节流过狠 | `card.*` / `chip.bet` 共用 **25 ms** 窗口 → 17 张发牌只响 2–3 声 | `card.deal` 改 90 ms 并按张数升 6% 音高；`card.play` 保持 25 ms |
| 无桌别质感 | 四桌共用同一套 `card.*` | 新增 `card.deal.texas/bj/ddz/uno` 四个变体（材质层不同，音量同一基准） |
| 胜负单一 | 只有 `win` / `lose` | 补 `draw`、`bust`（已有配方未接）、`sweep`（通杀/春天）三档 |
| BGM 不 duck | 音效与 BGM 各走各的 gain | 音效触发时 `musicGain` 降到 0.45、300 ms 内回落；连续音效不重复压低 |
| 手机外放发闷 | 合成音多在 200–600 Hz | 每个配方加一层 1.2–2.4 kHz 低幅泛音（peak ≤0.03） |
| 静音粒度 | 只有总音量 + 每游戏开关 | 加「只关 BGM」独立键（沿用同一音量档位，不做新 UI） |
| 回前台补响 | 已有 `document.hidden` 拦截与 AudioContext 恢复 | 加 1.5 s 抑制窗口：隐藏超过 5 s 后回前台，1.5 s 内不补播旧队列 |
