# 普通宿主调试入口位置与卸载重挂（2026-10-29）

本分支只修改`core/csh_debug.js`的悬浮球实例挂载/清理，新增`tools/probe_debug_drag_host.mjs`。版本4.1.0不变，未提交、推送或发布。没有修改主代理排行榜或另一分支反馈模块，也没有修改武将/牌规/金额/世界/存档数据。

## 当前界面与证据界限

当前池子调试和池子世界是顶层全屏面板，`#csh-dbg-panel`宽高100%、没有标题拖动把手。真正可拖的是单机对局的悬浮入口。实测标题原生拖动保持全屏布局，关闭/重开及宿主body缩放0.65/1/1.5下边界仍正确；不能将这些事实说成“完整面板拖窗功能通过”。本分支没有无证据新增可拖浮窗。

懒人包用户明确暂无，本轮没有懒人包/十周年UI环境，不能归因其右下吸附或称其已兼容。此处实际入口只在距离边缘24px以内吸附，中部原生拖动和保存自由位置通过。

## 已复现的缺口

1. 悬浮球卸载只删DOM，`document`的pointermove/up/cancel仍闭包持有旧球。受控禁用/重挂5次后新登记净监听数为3、6、9、12、15；追加100轮为21至318，随次数增长。
2. 手势中卸载再挂，旧pointerup仍能触发旧闭包的短按，误开幽灵面板。
3. 从别的显示器带回越界坐标时，挂载钳制用最初38px大小；美术观察器随后把球装饰为48px，右边实际超出约10px（旧结果x602、right650，640宽）。原resize只在视口变化时运行，不能感知此尺寸变化。

## 实施

- 每个悬浮球维护自身事件绑定清单。现有禁用卸载和重挂入口先清理旧实例，移除document/window/按钮的对应事件，取消闲置/视口防抖计时，断开尺寸观察器，清除旧指针状态及本实例resize引用。
- 保留原坐标读写、跟手阈值4px/拖动阈值14px、24px轻吸附、短按/原生click互为兜底、F1与全屏面板设计。未新增存储键或改变位置格式。
- 对实际入口尺寸注册ResizeObserver，装饰完成后按最终大小重钳制；无该API时仍在挂载后的现有120ms防抖重新量测一次。原resize/orientationchange继续工作，观察器随球销毁。

`source-proof.json`验证变化仅限mountFloatBtn/mountAll/disposeFloat及内部监听/唤醒/视口回调，外加一个模块内存cleanup引用。移除这些范围后，其余整个csh_debug.js逐字相同；面板打开/关闭、坐标读取/保存、业务页/规则/更新链均保持。

## 验收

同一完整无名杀宿主探针，**修前26通过/5失败 → 修后31通过/0失败**，两组均无运行异常/未处理拒绝。5项失败对应上述监听、手势和尺寸根因，不是5套不同业务Bug。

- 原生mouse跟手拖动、拖后不误开、保存中部位置、打开/关闭位置保留。
- 1365/915/844/640横屏及390竖屏、从大屏边缘收缩到640×286后纠偏；全屏面板独立于宿主body缩放。
- 5轮与追加100轮受控挂载/卸载，修后净document pointer集合一直为3；中途卸载不再误开。100轮是同步调用现有生命周期入口的压力测试，不冒充100次真人完整菜单操作或长期内存/实体设备验收。
- 原生F1开/关、CDP原生touch短按，重挂后只打开一个面板。测试没有用DOM.click替代这些输入。
- 观察操作钱包原文不变；截图已查看；目标语法、限定文件diff空白检查通过。

前后均使用临时Chrome profile、临时IDB/LS和localhost只读服务；为了受控触发已有私有卸载路径，只在测试返回的模块中导出两个函数引用，产品源码没有新增调试出口。body缩放模拟不等于Windows系统125%/150%设置、Android/WebView/Electron实体触摸，相关验收仍待条件。
