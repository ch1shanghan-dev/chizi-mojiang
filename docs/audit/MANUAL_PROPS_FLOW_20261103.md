# 局内四道具完整流程与成就反馈避让

日期：2026-11-03。作者要求本次多推进工作，本批完成一个较大的玩家流程及相关共享层修复。开发版4.0.14；1946条成就定义、285条可靠后台规则保持，扩容最后。未提交、推送、升版或发布。

## 玩家现在可以怎样使用

重启无名杀加载本地更新后，对局中打开一名存活AI角色的原生资料卡，选择 **批量互动 · 免费**，选鲜花、酒、鸡蛋或拖鞋及1/5/10个，核对对象和数量后送出。确认后回到牌局，顶部仅显示进度和“停止剩余”。这和图鉴购买羁绊分开，不消耗池子币，也不购买羁绊或改变战斗效果。

宿主原本没有四道具库存或币价，本批保留原生免费事实，没有编造库存、收费和退款。仍可使用原有四个单次表情入口。

## 本批落实

1. **原生入口与横屏构图**。扩展包装`get.nodeintro`，保留原资料卡和单次表情；批量选项单独按需打开。紧凑对象标题、左右两栏、主要内容优先，全部选择/确认控件至少44px、正文至少12px。1365×768、915×412、640×286可读可点；竖向只显示横置引导与取消。未公开武将以“这位牌友”称呼，不泄露姓名。
2. **明确对象、数量、免费效果**。支持四种道具×1/5/10；默认一个，选择后即时更新总量。发送前复核当前玩家、目标、牌局与存档；旧确认按钮、不同人物/旧局按钮不能发起新操作。原生特殊表情替换场景不添加批量入口，保留宿主原路径。
3. **有界原生演出**。每批只有一个活动任务，逐个调用原生`throwEmotion`，沿用原图片、音效、录像与广播实现；不造弹道/粒子或合成声音。650ms节奏配合原生约1.8秒动画，限制连续动作量，最多请求10个；不是一次铺满屏幕。完成后沿用花/蛋500ms、酒/鞋5秒的冷却，防重入。
4. **停止与减少动效**。显示实际已送出数量，可停止尚未发出的动作；停止不撤销已送出部分。系统减少动效默认只送一个，改变选项会先更新可见数量；不把“跳过”暗中当成全部送达。选择完成后不留下阻挡牌局的确认层或资料卡暂停。
5. **死亡、复活、终局和旧回调**。每步核对对象存活/归属、托管归属、牌局数组、存档代次和恢复锁。原生`dieAfter`只取消相关表现，死亡后立即复活也不会续播旧礼物或旧回应；终局、重置、换局、页面离开/隐藏均清理本批任务。不删除角色节点，不改行动、阵营或战斗AI。
6. **真实计数与恢复**。每个成功原生投掷继续走原玩家计数、资格和收据；按实际送出而非请求数增长。原生失败不计数，停止剩余不计数；保存失败进入既有待保存流程，提示到行囊恢复。重试只补存事实，不重播道具；免费互动不修改钱包余额，也不自动领奖。无新增存档格式，旧导出/导入继续支持。
7. **人物回应**。新增28句四道具接收回应，按现有公开世界牌风选择，缺少对应牌风时使用通用句；不读取隐藏手牌、不虚构关系史。完整批次最多回应一次，另有6秒全局节流和既有去重；尊重AI互动/台词开关，死亡、换局、换档后的迟到回应取消。受挫与高光的更多剧情仍是I01后续。
8. **成就反馈不会抢确认按钮**。新增可叠加的临时`achievementHold`。选道具期间暂缓通知，最后一个暂停来源释放后恢复原反馈；不删除历史、不消费奖励，不通过抬高新面板层级解决。既有回顾、后台/前台和恢复流程保持。

- 门禁发现新样式和上批人物“展开”提示的裸字号；已改为现有同值字号变量，没有扩大标题。
