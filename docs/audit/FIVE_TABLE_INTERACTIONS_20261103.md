## 本批完成的五项

1. **廿一点规则与保险层（P1）**。原先阅读规则/选择保险时，H/S/D/P/R仍可能作用于底下牌桌；两层并存时Esc先拒绝保险。现在只处理顶层，先退出规则，再明确处理保险；Tab留在弹层内，打开和关闭恢复合适焦点。输入框、组合键、输入法和按住不放的快捷键不出牌；按钮保留原生Enter/空格。保险费、赔付、基础策略和牌局推进未改。
2. **德州签到与输入（P1）**。原先Esc及卡外点击会执行签到，失败也可能显示“今日已签到”。新增“稍后再领”，Esc/卡外点击仅收起；领取处理中明确反馈并锁定本次操作，ACK失败可重试，重复/迟到/卸载回包不重绘旧页。保留原钱包签到、官阶加成和独立模式计算，镜像日期取发起日。按钮改称“领取补给”，不暗示自动开桌。输入时的F/C/R/A、组合键和重复键不下注；签到/加注/结算层打开时隔离牌桌快捷键。不恢复玩家难度。
3. **UNO选色与摸牌决策（P1）**。原选色状态不随换轮/托管清理，摸牌按钮闭包可保留旧牌；选色层还可能被后面的摸牌层盖住。现在核对房间实例、房间ID、轮次、当前行动者、摸牌ID及当前可出手牌；失效即清理，发送前再次核对、消费本次决策，关闭期间不发送。选色层位于摸牌层之上，取消保留当前有效摸牌决策，Tab留在顶层，隐藏决策层不保留不可见焦点；取消控件至少44px。原Room规则、AI、收费/排名/世界恢复路径未改。
4. **斗地主取消手势与右键（P1）**。原鼠标/笔pointerdown设置的click抑制标志在取消后残留，下一次触摸会被吞；右键也会选牌。现在仅主指针左键走即时点选，pointercancel/窗口失焦/下一次触摸清理残留，配对click仍只选一次。保留触屏横滑及原托管禁选，不修改组合牌判断、阵营、AI或结算。本项清理事件抑制状态，不声称实现任意手势撤销。
5. **生涯人物档案（P2）**。姓名、牌风、说明及有来源的状态为默认主体；资金、牌局、胜局、最大底池收入“牌桌记录”，可用键盘展开。去掉默认显示的内部牌技小数，未知数值/状态明确未记录，不补造零或人物经历。矮横屏固定姓名与关闭，正文单独滚动；关闭返回原人物，原行被刷新移除时回到搜索。官阶弹层移除人物专属布局，保留原内容。
