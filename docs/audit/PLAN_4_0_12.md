# 4.0.12 体验与视觉重构实施方案

日期：2026-10-26。基线c373fc6/4.0.11。作者授权先整理反馈，再按方案自主实施。武将AI仍暂停；郝昭只补语音，不改机制与AI。真人存档不用于测试，旧已领取记录不清除。

## 反馈整理与设计目标

1. 悬浮入口恢复“池”字，采用小型金石印章；当前龙纹图标缺少含义，与名称识别脱节。
2. 郝昭补合适配音，优先核查本机既有郝昭语音及阵亡语音；资源随扩展携带，字幕与实际声音一致。
3. 对局CBY奖励由扩展固定配置，移除玩家自由编辑入口和可编辑面板；旧自定义值保留在旧档但不再参与发奖，固定值与说明同一来源。
4. 妖灵覆盖原2–8人场（实际3–9席）。目标是真人首次准备阶段召唤，而不是仅提前生成后演出；先验证当前引擎动态加人、9席距离/座位环、初始手牌、回放和正常回合。只有真实兼容通过才启用，失败回滚原席位；内奸/联机/观战仍跳过。
5. 调试按钮修复图形、文字的几何中心与视觉中心，消除角色名按钮偏移；不靠缩字掩盖。
6. 世界/生涯/游戏采用“墨池·金石”方向：深墨青、暖象牙、少量鎏金，主次按钮区分；减少大面积空黑与多种金框混用，增大角色卡和牌桌主信息层级，布局适配比纹饰更优先。
7. 生涯成就奖励分层提高：保留493条和旧key，未领奖励至少500，原基础奖励按5倍并取整；高阶奖励继续体现难度，已领不重复追发。增加宿主复核的一键领取，单项失败不假报全成功，可重试不重复。
8. AI世界丰富可读性和人物关系：根据真实个人同桌经历、胜负/交手次数、财富/状态生成“池中风向”“熟人邀约”“人物近况”，给出可行动线索；不虚构玩家完成事件，不读暗牌，不加入武将决策Hook。沿用有界存档与离线动态，避免无限日志。
9. 救济从“低于最低门票”改为低流动资金回桌援助：余额不足2000时每日一次补足至3000。展示具体门槛、可得金额和今日状态；余额/日凭据同写，失败不消费资格，不能连续刷取。高余额玩家显示明确原因，不伪造可领取。
10. 德州取消20上限，保留当前1%默认、费率可选、见翻牌后收费、未跟注免收和整场不双扣。只移除上限，不改变底池与筹码规则；按总争夺底池整数费额分配余数，避免分层时漏/重计。

## 固定奖励初值

身份300/100、对决250/80、斗地主300/100、国战400/120、挑战普通终局150/50（胜/负）；其他模式250/80。BOSS击破与辅助身份隔离继续沿用。数值是本轮产品默认，不当作实测收益结论。

## 额外审美与交互优化

- 主操作统一高度和光照，文字不压进装饰边框；危险操作保持暗红且不抢主按钮。
- 世界首页增加欢迎区/今日风向/清晰分组入口；图标只作辅助，常用模块一步可达。
- 牌桌增加有深度的墨绿毡面、内外桌沿、清晰座位卡与居中的街道/底池；底部操作按决策顺序，避免数值挤成小字。
- 成就“一键领取”旁显示可领数量和总额；处理中锁按钮，完成后给本次实际到账与剩余待领，而不是弹几十个提示。
- 减少动效与低性能模式可用；安全区、焦点、触摸面积、窄屏与矮屏都要验收。

## 分批实施与验收

A 经济与声音：固定奖励、救济原子性、提高成就与批领、无限额场供、郝昭音频路径/字幕，故障/重试/旧档验证。
B 妖灵：准备阶段动态入席、9席布局、身份与完整原生回合/胜负/普通统计隔离；新增实体获得正常初始手牌，回放动态加人可重放。
C UI与世界：中心对齐、印章、世界/生涯/小游戏共用视觉基座，真实数据人物故事与可用入口；桌面/窄屏/矮屏截图及实际点击验收。
