# 池子魔将 · 玩家体验与边界优化实施方案

2026-10-28更新（原方案建于2026-10-27）。作者已授权依据审查继续实施；覆盖此前‘只读、暂不施工’限定。本地版本保持4.1.0，不自动提交/推送/发布，不修改武将战斗AI、技能规则、人物立绘或音频资源。

## 目标

玩家能看懂本局规则和当前状态；正常关闭不丢结算；保存失败可重试/重载恢复；行囊预览与实际覆盖一致。手机横屏与电脑均验收。保留1380池子成就、493生涯及全部旧奖励与已领凭据。

## 妖灵规则选择

保持独立身份AI角色。阵亡退出行动但保留原生死亡记录/席位；不补召；复活只恢复本局剩余次数；主人死亡后仍按原身份作战，对主人的支援停用。已经预约的局沿用辅助资格，未实际入场就终局按中止说明，不伪装普通奖励局。支援仍3次减1伤、3次摸1、1次回1体力；不承诺必救。守护形态明确区别于挑战形态。

每批记录改动、前后同一故障探针、真实宿主证据与未验项；不删除失败断言。临时材料/备份仅放仓库外work，项目报告放docs/audit。本机/安卓平台与后端实机条件不足时明确列待验，不写成全平台完成。
