# 生涯比例成就可靠记录：单轮续工

2026-11-04。仅WorkBuddy独立副本，版本4.0.14；无安装、提交、推送、生成ZIP。本轮到此收尾。正式安装6项文件哈希与修改前基线一致，见formal-unchanged.json。

## 问题与结果

新增22条比例成就分类为“比率”，原观察器只按“胜负”与“豪赌桌”分类采集，导致这些条目虽能在页面判定当前达标，却没有可靠首次资格记录。胜率或局均值下降后可能失去未领资格。已接入原严格来源：个人12条（胜率6、局均击杀6），豪赌10条（局均净赢5、胜率5）。

个人资格与实际个人对局记录在同一次钱包保存中写入；豪赌资格与结算来源同写，再由原队列聚合到钱包。样本门槛仍为个人50局、豪赌100局；奖励和原ID不改，不自动发钱。达标后比率下降仍保留资格及原时间，领奖继续去重。

迟装观察器时，个人比率会重放真实完整来源回执，不能只因当前比率已低于目标就略过过去达标。超过512条的无损紧凑回执也验证可恢复原第50局日期。豪赌缺少历史首次来源的旧档只能保留未知日期，不宣称可追溯任意过去瞬间。

另发现既有cx_ratio_killper_1.2、cx_ratio_killper_1.5含小数点，会被原生涯资格和领奖键校验拒绝。仅精确兼容这两个已经存在的ID；其他带点的任意键仍拒绝，原危险键检查保留。两个ID的导出、导入、防重领奖均通过。
