# 联网与离线客户端架构（4.1.0本地候选）

日期：2026-10-28。此文只描述已实施客户端；当前唯一服务描述为legacy-board-v1，HTTPS旧社区榜，只读，写能力固定关闭。

## 请求及保存方向

| 层 | 责任 |
| --- | --- |
| csh_online | 本机偏好、可信来源、开关代次、跨同源iframe共享策略、活动请求取消；加载不联网、不生成身份 |
| csh_net | 旧协议GET /board、GET /girls适配，POST /submit与/cheer保留调用契约但受写权限闸门阻止；有界传输、退避、分槽快照 |
| rank / codex | 本机内容先呈现；仅公开区域可失败；旧响应核对上下文，失效不渲染/缓存/确认待报 |
| wallet / cheer | 原经济账本与耐久应援outbox；没有网络依赖、远端不能覆盖余额或重写成就 |
| debug / update | 离线时不探测源；开启后手动读取资源走显式入口；仍使用既有暂存、摘要、备份及回滚实现 |

网络请求没有全局劫持引擎fetch；开关只管本扩展主动发起的远端访问，无法代表引擎或其他扩展全部断网。包内资源、引擎脚本和本机桥仍可读取，不等待网络初始化。

## 本机元数据

| 键 | 内容/限制 | 迁移行为 |
| --- | --- | --- |
| csh_online_policy_v1 | v/enabled/publishFor；默认关闭；坏值/读取失败关闭；显式设置读回确认后采用 | 不导出/不从他人档继承 |
| csh_rank_cache_v2 | 服务ID+协议+榜型+页码1+身份分槽；最多12槽、序列化长度1MiB上限；行50/妖灵100/题壁160字符；保存时间 | 非玩家资产，排除；v1仅匹配本榜/原旧服务读取，保留旧键 |
| csh_online_backoff_v1 | 每服务/路由最多12项，指数延迟与抖动，上限约15分钟；成功复位；未来异常时间忽略 | 非玩家资产，排除 |

既有在线UID、昵称与题壁不会由于看公开榜而上传，不生成新UID。普通成绩待报保留原键；应援待报仍在钱包cheerState，按原UID/CID保留。缺当前身份时显示其他原身份待报数量；离线、无服务或权限不足均不清除，不做自动退款/改投新服。

## 传输限制

旧业务协议：HTTPS固定来源和四路由，JSON请求4096字节、响应512KiB，默认4.5秒/最长10秒，Node与fetch均限流读取、回调一次；错误体也受限制。浏览器无环境凭据、无referrer、拒重定向；Node不关闭证书校验、不跟重定向。最多4个活动请求；自动调用受持久退避限制，手动重试也至少间隔1秒。无无穷定时重试。

资源入口：仅可信HTTPS列表，GET/HEAD，15秒及开关代次取消；文本/JSON512KiB，单个二进制16MiB。缺流式读取能力时拒绝下载并指向完整安装包，不退回无界读取。打包商店数据仅同源或file同协议且精确store.json路径读取。新增来源需代码审查，服务器不能下发任意地址。

新响应必须是JSON对象；公开榜控制器还要求ok和对应数组，采用前做字段清洗。现有适配保留旧服务兼容，不能据此认为完成新版服务器schema、鉴权、签名或防作弊。更新完整性仍依赖可信发布源摘要，未实现独立签名基础设施。

## 用户看到的状态

未开启→显示本机历史最佳/对应快照和离线说明；开启→说明旧服务与IP可见，只读取公开榜；失败→保留原快照或显示未同步，不把未知数字变0。更新与商店仅在玩家主动操作时发起。本机题名按钮说明只保存在本机。图鉴题壁注明公开快照日期。

全球应援按钮与补报在写服务未验收时禁用，并先于宿主扣款入口拦截。已有待报仍可导出保存；没有可验证旧身份映射前不承诺送达新服务。
