# 池子魔将 · 玩家体验与边界优化实施记录

2026-10-28。本地版本 **4.1.0**，HEAD仍c825879；本轮完成方案中的六批本地实现与相应验证，尚未提交、推送、打tag、发布或更新桌面ZIP。作者最新“根据优化方案进行工作”已覆盖上一轮只读限定。

## 玩家现在能感知的变化

1. **结果保存失败看得见、能继续处理。** 普通奖励、辅助战绩、池子成就终局、每日任务使用本机待保存结果簿；行囊显示待保存状态并可重试，世界页提供恢复入口。已保存的收据防止重复发放。连结果簿也写不下时会明确提示保持页面打开，不能承诺重启后恢复。
2. **正常关窗先完成结算。** 斗地主和UNO在成功确认前保留操作区；失败不会只剩空白页面。真实宿主额外发现旧钱包“先成功、后防抖保存”的深层问题，本轮一并改为严格保存后确认。钱包流水镜像失败则保留已入账检查点，不把已付款误报为未付款。
3. **行囊先解释变化再导入。** 保留8类核心摘要、28类折叠及全部36类导出；新增存档文件选择，读取后自动只读校验。预览与真实写入共用计划，显示内容变化、可能回退、合并及保留本机；相同数量不同内容也能被发现。选择文件不等于执行导入。
4. **妖灵状态有明确规则。** 可查等待、守护中、阵亡、主人阵亡、暂停、结束、中止；额度与当前可用性分开。主角原生“灵”标记、设置中的“本局妖灵状态”提供入口。辅助战绩在生涯大厅独立展示。
5. **专属成就更好读。** 保留原80+新增1300=1380项，100位武将每人13项；独立493生涯不合并。选中武将后按三条特色成长路线、长期里程碑、同局组合分组；同局挑战显示当前/刚结束一局的条件进度，不把不同局拼起来。批领按钮明确为“领取全部已达成”，手机横屏保留重要条件提示。
6. **互动和费用更可信。** 终局按模式判立场，未知结果说中性话；每局终局话只一次。结契显示CBY总价，高阶互动显示实际门槛，取消追踪失败显示原因。辅助形态可映射世界本体。
7. **更新有暂存、核验、备份与恢复。** 相同版本也可比较构建；相同摘要的文件跳过。安装中途失败不自动重启，取消后旧下载不能写回安装目录。远端缺完整文件摘要时提示使用完整安装包。未对真实安装执行在线更新。

## 妖灵阵亡究竟怎样处理

采用原生死亡：从game.players移出、进入game.dead，停止回合行动与支援，保留死亡节点与席位。直接销毁角色会破坏原生死亡/复活/身份判断的引用，因此不这样处理。

真实宿主受控调用原生die验证：总5席时存活角色从5降到4；妖灵在game.dead中、节点有dead类、辅助资格保留。状态显示“已阵亡”“当前不能提供支援”，主人仍有“灵”标记，未请求缺失的辅助别名死亡音频。这里是一次受控原生死亡，不是自然打完一局，也不是50位妖灵逐一实战。

| 情况 | 当前规则与玩家说明 |
| --- | --- |
| 预约但未到本人准备阶段 | 显示等待；不提前生成支援收益 |
| 正常入场 | 独立AI角色、3体力、4起始手牌，使用守护形态通用四技能 |
| 妖灵阵亡 | 停止行动/支援，不补召；保留原生死亡席位与记录 |
| 妖灵复活 | 使用本局剩余次数，不重置3/3/1，不另召一只 |
| 主人阵亡 | 妖灵继续按原身份参与牌局，对主人的支援停用 |
| 主人身份变化/控制切换/存档恢复 | 支援暂停并显示原因；恢复合法会话后才可继续 |
| 濒死回复 | 本局一次回复1点体力，不保证从负体力脱离濒死 |
| 预约后未入场就结束 | 辅助资格不变，辅助胜负记中止；不伪造普通奖励局 |
| 已入场的辅助局结束 | 独立辅助胜负，无普通场奖励与池子成就；保存失败可补记 |

## 存档与更新的边界

- 本机待保存结果不作为跨设备任务导出。正常导出先排空；无法完成时阻止导出并提示。导入、回滚、重置采用新档时取消旧局待办，避免旧结果污染新档；失败回滚保留旧状态。
- 每日任务的旧兼容键写失败不再导致重发奖励。余额与任务已领在钱包同写，流水可以补写；满额不能全额发放时保留资格。
- 小游戏本轮保证被测试的结算失败留页与重试路径。尚未建立整个进行中房间的跨进程存档；不能声称强杀应用后牌局与所有机器人资金、功勋均有一个跨后端原子恢复点。
- 导入逐域预览使用与写入相同的buildImportPlan；钱包保全副本、名字和音乐键族/CDK合并也按实际计划计算。预览只读，不提前提交。
- 更新备份和暂存放在扩展外的本机更新区，校验成功后逐文件提交。进程内故障回滚、残留凭据恢复已做故障验证；**仍不是目录原子切换**。强制断电恰逢入口文件替换时，扩展可能需要完整安装包恢复，不能靠尚未成功加载的界面保证自救。
- 原文件备份保留在本机，便于恢复，可能增加磁盘占用；本轮没有实现跨多次更新的备份保留数量管理。记录此项为后续维护，不擅自删除玩家已有备份。
- 联机、回放和特殊身份仍按原守卫限制；本轮没有扩大联机资格，也没有接入生产榜单或新AI服务。

## 未验收与后续顺序

1. **Android/WebView与Electron实机。** 横屏真实缩放、大字号/软键盘、原生文件选择与下载、后台再进入；更新原生文件接口及短文件截断。浏览器使用隔离配置与只读宿主服务，不能冒充这两种平台。
2. **自然对局。** 100位逐一完整实战；各模式自然终局；UNO结束立刻关窗、丢ACK和多轮，德州边池/全押、廿一点分牌等复杂分支。本轮没有修改这些牌规，也没有声称全穷举。
3. **更新强制中断。** 在专用测试安装上逐提交点杀进程，再验证完整包恢复/备份保留策略；完成前不写“断电安全”或“任何失败均可启动”。
4. **应援后端。** 生产认证、幂等归属、重名/设备变化、ignored回执需要隔离后端资料。HTTP错误体解析不等于服务端问题已解决。
5. **呈现继续深化。** 熟面孔/再战叙事优先显示玩家亲历；成就推荐优先有进度且接近达成的目标；未来需要跨次更新备份管理。均以减少玩家判断成本为目的，不再盲目堆入口和台词。
