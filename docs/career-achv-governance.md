# 生涯成就形态治理方案（v1 · 2026-10-20）

> 背景：生涯成就 465 条（`core/csh_achv.js`），>95% 是「同一字段换阈值」的阶梯。
> 池子成就（80 条操作型）上线后，生涯大厅应做减法：删掉纯凑数档位，保留真正的里程碑。
> 本文是治理的**唯一方案真源**：形态分类、减法原则、兼容机制、执行流程。

---

## 1. 形态分类（实数：465 条 / 66 族）

| 形态 | 判定方式 | 族 | 条数 | 评价 |
|---|---|---|---|---|
| A · 线性阶梯 | 同一 stats 字段 ≥10 档 | rank(50)、merit(23)、interact(20)、rich(18)、peak(18)、sign(16)、games(16)、wins(16)、hands(16)、meritday(14)、loses(14)、kills(14)、retired(14)、gmplay(14)、gmbest(12)、task(12)、gmnet(11)、topdown(10)、broke(10)、gmwin(10)、gmstreak(10) | **321** | 凑数重灾区 |
| B · 短阶梯 | 同一字段 3~8 档 | poorai(8)、topfund(8)、skilltop(8)、gmbust(8)、chars(6)、billionaires(6)、gmloss(6)、seg(5)、worldchars(5)、worldrec(5)、tierdown(5)、poor(4)、modes(4)、comebacksee(4)、rivalsee(4)、grudge8(4)、gstreak2(4)、bosskill(4) | **96** | 部分有里程碑价值 |
| C · 事件/封顶型 | 单一条件、一次达成 | 彩蛋 11 条（egg_*）、挑战全破/速通 14 条（boss_*）、boss_asboss(3) | **28** | **真正的成就**，全保留 |
| D · 反向见证 | atMostAfter（先有经历再压线） | topdown、poorai、poor 等 | （计入 A/B） | 形态健康，但档位可减 |

结论：**减法主战场是 A 形态的 21 族 321 条**；C 形态 28 条一条不动。

## 2. 减法原则

1. **里程碑留存**：每族只留「认知上有意义」的档位——首档（第一次）、整十/整百、顶格、以及有特殊文案的（如 `seg_*` 段登顶、`rank_50` 大将军）。
2. **密度上限**：任一字段族最终 ≤6 档（参考：rank 50→10，merit 23→8，sign 16→6）。
3. **奖励重算**：留存的档位奖励不变；被退休档位的奖励**不补发不回收**（见 §3）。
4. **作者终审**：每批退休清单（key 列表）在提交信息里完整列出，作者可一键回滚（删 RETIRED 里的键即恢复展示）。

## 3. 兼容机制（退休层 · 已在 csh_achv.js 落地）

**不删定义、不动存档**，只做「软下线」：

```
RETIRED = { "rank_7": "R1", ... }   // key → 批次号
```

`evalAll` 输出规则：

| 玩家状态 | 退休前 | 退休后 |
|---|---|---|
| 已领取 | 可见「已领取」 | **照常可见**，标「绝版」 |
| 未领取但已达成 | 可见「可领取」 | **照常可见可领**，标「绝版」 |
| 未达成 | 可见进度条 | **不再出现** |

- 存档 `csh_career_achv`（已领取集合）**永不修改**——已发奖励零风险；
- 总量统计（`已达成 X / 总数`）自动随 evalAll 收缩，玩家看到的是「新总数」；
- `selfTest` 校验：RETIRED 指向不存在的 key 直接报错（防笔误）。

## 4. 执行流程（每个减法批次照此办理）

1. 从本方案 §1 的 A/B 族里选 1~3 族，列出退休 key 清单（写进提交信息）；
2. `RETIRED` 逐键登记，值为批次号（R1、R2……）；
3. 跑门禁（E50 总数断言等如报错则同步更新）+ vm 自检（退休条目三态行为）；
4. **禁止整族清空**：一族至少留首档 + 顶格；
5. 彩蛋 / boss 全破 / 速通（C 形态）永不进 RETIRED。

## 5. 与池子成就的分工（防止再长回去）

| | 生涯成就 | 池子成就 |
|---|---|---|
| 回答 | 你积累了多少 | 你打出过什么 |
| 形态 | 快照阈值（允许 ≤6 档阶梯） | 局内事件（一次对局可完成） |
| 新增纪律 | 新字段才有新族，同字段不加档 | 事件白名单 8 个，禁阶梯 |
