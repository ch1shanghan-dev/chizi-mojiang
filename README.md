> 无名杀（Noname）武将扩展 · 当前版本 **4.0.13**（开发迭代版，本次同步GitHub）

一套以「魔将」为主题的无名杀扩展：在标准对局之上补一整套武将、卡牌与技能，
外加若干可选的衍生玩法（小游戏、BOSS 挑战、生涯与经济系统）。

## 内容

| 模块 | 规模 | 说明 |
| --- | --- | --- |
| 武将 | 100 名 | 原生注册，支持联机 |
| 卡牌 | 24 张 | 随扩展启用 |
| 技能 | — | 与武将配套，含限定技 / 觉醒技 / 转换技 |
| BOSS 挑战 | 93 魔王 + 50 妖灵 | 独立模式入口，含讨伐录与图鉴 |
| 池子休闲 | 6 个小游戏 | 德州 / 廿一点 / 斗地主 / UNO / 金鳞市 / 妖灵图鉴 |
| 生涯系统 | 成就 · 官阶 · 经济 | 单机向，联机时自动休眠 |

**分层原则**：衍生玩法只观察对局，对局内容不依赖衍生层 —— 删掉 `core/` 后，
武将 / 卡牌 / 技能 / 立绘 / 语音 / 联机仍可完整游玩。

## 安装

**方式一：压缩包（推荐）**

1. 到 Releases 页面下载最新的 `chizi-mojiang_vX.Y.Z.zip`；
2. 在无名杀的扩展目录下新建文件夹 `池子魔将`，把压缩包内容解压进去
   （`info.json`、`extension.js` 应直接位于该文件夹根部，不要再套一层）：
   - Windows：`无名杀/resources/app/extension/`
   - 安卓：`游戏根目录/extension/`
3. 重启游戏 → 「扩展」页找到「池子魔将」→ 开启 → 再重启一次。

**方式二：游戏内导入**

把 zip 直接拖进无名杀窗口，按提示导入并重启（压缩包根目录已含 `info.json`，可直接识别）。

## 更新

扩展内提供「检查更新」：进入扩展设置面板 → 检查更新 → 立即更新。
更新只重下代码、素材仅补缺失，完成后自动重启。

## 兼容性

- 无名杀 1.10.x ~ 1.11.x（实测 1.11.6）
- 与十周年UI 共存：自动识别并接入卡牌皮肤 / 前缀角标 / 动态皮肤；未安装时静默跳过
- 联机：武将本体可单向联机（客机未装扩展也能进房），衍生功能在联机中自动关闭
